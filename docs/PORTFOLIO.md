# Project profile

## GitHub description

Self-hosted messaging with a Telegram-derived Android client, Go/PostgreSQL backend, Signal encryption and bilingual administration. Development preview.

## Short English résumé entry

**VYRN — Self-hosted messaging platform**

Android/Java · Go · PostgreSQL · REST/WebSocket · Docker Compose · Signal

An independent messaging stack integrating a pinned Telegram-derived Android UI with a custom Go backend, durable local message queues, per-device Signal encryption, invite-based accounts and an English/Persian administration panel. Includes container deployment, encrypted backup/restore tooling and automated backend integration/race checks.

## Attribution and honest scope

The Android UI is derived from DrKLO/Telegram; VYRN's contribution is its independent integration, backend, branding and operation tooling. Do not describe it as an original Telegram UI or audited production messenger. Public source, scoped tests and project ownership are separate from final Release signing, complete acceptance, usage figures and independent security review. Only claim personal responsibilities and measured outcomes you can substantiate.
